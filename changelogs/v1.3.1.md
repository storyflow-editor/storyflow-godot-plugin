##### New Features

- **Dialogue Rollback**: Enable Dialogue Rollback in StoryFlow Editor's project settings, export again and the plugin keeps a bounded history of earlier dialogue steps. `go_back()` on the dialogue component returns to the previous interaction and restores story globals and locals, script and loop positions, once-only choices, character values, Data Asset runtime writes and the story's random stream. The supplied UI scripts connect an optional scene-unique **BackButton** automatically, with **Author Allows Back** for your own enabled condition, and `rollback_availability_changed` tells a custom UI when to enable its button. Rollback is off by default and costs nothing while it is off

- **Block Rollback**: Call Block Rollback, or place the Block Rollback node in a story graph, before work that cannot be undone, such as granting an achievement or writing to a server. It clears the retained history, so Back cannot cross that point

- **Localized Data Asset Overrides**: A string a child Data Asset overrides is now translated like the declared value it replaces. Fields that opt out of localization in StoryFlow Editor stay as authored

- **Configurable Script Nesting Limit**: The maximum depth of Run Script calls follows the project's setting in StoryFlow Editor, so the plugin stops a runaway chain at the same depth the editor does

##### Improvements

- **Error Reporting Matches StoryFlow Editor**: A missing script, a missing flow and a Start node with nothing connected now raise the same errors the editor shows, including when the story itself starts on such a script. A Run Script with no script and a Run Flow with no flow only warn

##### Bug Fixes

- **For Each Loops Stopped After Their First Element**: A loop whose body ended on an unconnected Random Branch or Switch On Enum output, a Block Rollback node, an empty flow, an empty Loop Body or a Run Script with nothing connected after it stalled on the first element and never reached Completed. The loop now moves on to its next element, whichever node the body ends on

- **Long Loops Stopped or Crashed**: Each iteration nested a call, so a loop stopped near 290 elements and could crash Godot 4.3. Iterations now run in place and long array and map loops run to the end

- **Loops in Called Scripts Lost Their Place**: With rollback off, a called script cleared its caller's loops when it ended, and a loop it left through End resumed mid-way on the next call. Caller loops now keep their position and an abandoned loop starts over

- **For Each Followed Its Array While Looping**: Adding to an array inside its own For Each body never ended. A loop now iterates the elements it had when it started

- **Set Array Element Did Nothing**: The node now writes the element back to the variable behind its array input

- **Set Array With Nothing Wired Emptied the Variable**: A Set Array node whose array input is not connected now leaves the variable as it is

- **Arrays Were Shared Instead of Copied**: A wired Set Array, an array passed to a called script and an array operation's input all handed over the same array, so a change on one side showed up on the other. Each now works on its own copy

- **Add To String Array Ignored an Empty Wired Value**: An empty string arriving through the wire now adds an empty string instead of the node's inline value

- **A Dead End Left the Line Refusing Input**: A line whose advance leads nowhere stays usable instead of refusing further input

- **Exit Flows With No Route Dropped the Script's Loops**: A called script that ends on an exit route nobody connected stays in the script and keeps its loops intact

- **Unwired Run Script Parameters**: A parameter left unconnected now passes false, 0, an empty string or an empty array, as it does in StoryFlow Editor, instead of the called script's default

- **Start Flow Matched by Any Casing**: A flow named `Start` was treated as the Start flow. The id is now matched exactly
