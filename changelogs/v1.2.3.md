##### Bug Fixes

- **Reset stranding the running dialogue on stale variables**: calling `reset_global_variables()` mid-session — for example a "Reset Game" fired from a dialogue tag on a main-menu node — left every branch in the running dialogue evaluating against the pre-reset values, no matter what was written afterwards. The reset rebound the globals to a fresh dictionary, but the running dialogue's evaluator holds that dictionary by reference from dialogue start: reads kept hitting the orphaned copy while writes landed in the new one. The reset now clears and refills the same dictionary in place, so every live reference observes it. A regression test pins the contract: a reference taken before a reset must observe writes made after it
- **Cross-script image and audio references resolving to null**: a value can cross script boundaries at runtime — a character's Image set from one script's local image variable is still displayed while another script runs. Asset resolution falls back to the project pool for anything outside the running script, but the pool only knew project-level assets, so such references came back empty (a character portrait assigned during one script vanished in the next). The importer now mirrors every script's resolved assets into the project pool; asset IDs are globally unique across an export, so the mirror is collision-free
